# 前端界面设计决策

## 状态

- 状态：已确认
- 日期：2026-09-01
- 适用范围：首版桌面端前端

## 设计目标

easyBlog 的核心价值是便捷地把内容发布到 GitHub 博客。界面应围绕“发现变更、确认内容、完成发布”组织，而不是把写作编辑作为主要工作区。

产品面向个人作者，首版只优化桌面端，不实现移动端布局。

## 继承自 PRD 的产品约束

以下行为由 [PRD](../PRD.md) 和相关专题文档定义，前端只负责清晰呈现和编排：

- 内容源支持本地目录、飞书文档和飞书知识库。
- 内容源单向发布到 GitHub，GitHub 不反向写回。
- 检测与发布分离；默认每 30 分钟检测，也支持手动检测。
- 变更包含新增、更新、删除、移动和冲突；删除必须用户确认。
- 每篇文章只能绑定一个来源；重复来源、slug 冲突和目标端外部修改阻止对应发布。
- 发布支持拆分批次，并包含预览、stage、commit、push、失败重试和历史回滚。
- 凭证由系统安全存储管理，日志不得包含正文或凭证。

## 本次确认的界面决策

### 应用框架

- 使用左侧固定导航，入口顺序为：工作台、来源、变更、发布、历史、设置。
- 工作台是默认落点，启动后优先呈现当前可发布状态。
- 首次使用采用三步 onboarding：连接来源、配置 GitHub 目标、完成首次检测。

### 工作台与变更

- 工作台以待发布变更列表为主，来源状态和发布摘要为辅助信息。
- 变更默认按类型分组：新增、更新、删除、冲突。
- 默认筛选可直接发布项；冲突、警告和其他阻断项保持可见，并在顶部显示摘要。
- 变更条目显示标题、来源、变更类型、更新时间、目标路径、状态、转换警告和预计影响文件数。
- 来源目录树按需展开，用于按来源筛选或选择范围，不常驻占用主工作区。

### 预览与发布

- 选中变更后显示固定底部发布栏，包含已选数量和“预览发布”入口；未选中时收缩为状态条。
- 发布批次支持任意混合选择的文章集合，并提供“全选本次变更”快捷操作。
- 点击条目在右侧详情面板打开预览，列表保持可见。
- 详情面板提供来源内容与目标 Markdown 的左右 diff。
- 删除项单独分组且默认不选中。
- 冲突、slug 冲突、权限错误等阻断项自动剔除出可发布批次，不阻塞无关内容。

### 异步状态与恢复

- 检测、转换、提交、推送等异步过程在页面内按阶段展示状态、耗时、失败项和重试操作。
- 发布失败时优先展示失败阶段及“重试该项/重试全部”；详细日志放在可展开的诊断区域。
- 历史页提供发布记录和 commit 信息；回滚位于单条记录的更多菜单中，不与正常发布并列突出。

### 视觉与桌面体验

- 视觉方向为“纸上水墨”（2026-11-18 修订，取代原先偏 Git 客户端的中性风格），细则见下方“视觉系统”。
- 没有待发布变更时，空状态显示最近检测时间和“立即检测”操作。
- 提供命令面板，承载检测、搜索、发布预览和页面切换等高频动作。
- 主题跟随系统，首版提供浅色和深色两套主题。
- 默认使用宽窗口，支持调整大小；关键工作区布局设置合理的最小宽度。

## 视觉系统（2026-11-18 修订）

灵感来自游戏 GRIS 的水彩与墨线画面：大面积留白、一团珊瑚红的云、极细的墨线。界面是铺在画面上的一张纸，画只在侧栏、窗口边缘和页面标题后方露出，内容区保持安静。

### 颜色

- 暖色邻近色（米白、淡粉、珊瑚红）只负责氛围，占大面积；梅子墨色 `#2e2130` 负责文字和主要操作；互补的青绿 `#2b7a71` 只用于焦点环和“已完成”。面积比例约 60 / 30 / 10。
- 珊瑚红是装饰色和“当前项”标记，不作为主按钮色，避免与危险操作的深红混淆。
- 状态色：成功为青绿、提醒为赭石、危险为深红；状态一律同时带文字，不单靠颜色表达。
- 对比度下限：正文和辅助文字不低于 4.5:1，输入框边框和焦点环不低于 3:1。新增颜色前先核对对比度。
- 所有颜色都定义为 `src/styles.css` 顶部的变量，组件里不直接写新的色值。

### 字体

- 只使用系统字体，不引入字体文件。
- 标题（20px 及以上）使用衬线字体栈（Iowan Old Style、Palatino、宋体），字重 400；正文使用 Avenir Next、Segoe UI、苹方。
- 最小字号 12px；路径、提交号和 diff 使用等宽字体。

### 画面与形状

- 背景画的源文件是 `docs/design/gris-scene.svg`，导出为 `public/gris-scene.jpg`（2400×1500）。构图约束：左侧 300 单位保持浅色（侧栏文字），顶部 250 单位保持柔和（页面标题）。
- 重新导出：用 Chrome 无头模式把 SVG 以 2400×1500 渲染为 PNG，再用 `sips -s format jpeg -s formatOptions 80` 转成 JPG。SVG 根节点带固定宽高，需要放进 `<img>` 并指定尺寸后再截图，否则只会渲染左上角 1600×1000。
- `public/paper-grain.svg` 是叠在画面上的纸纹。
- 卡片使用略不对称的圆角，按钮为胶囊形；分隔尽量靠留白和底色，少用边框。

### 文案与点击

- 页面标题不加眉题和说明句；只在空状态和出错时解释。
- 整张卡片或整行可点击时，由行内已有的按钮撑满整行，不额外增加按钮。
- “预览发布”在评审的每一项上都可用，不要求先翻到最后一项。

### 尚未实现

- 深色主题尚未实现，当前只有浅色一套。

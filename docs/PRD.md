# easyBlog 产品需求文档

## 1. 产品定位

easyBlog 是一个单用户、单机、本地优先的桌面博客管理工具。它低频检测本地文件、飞书文档和飞书知识库的变化，将用户确认的内容以 Git 提交发布到个人 GitHub 博客仓库。

## 2. 首版目标

- 支持本地目录、飞书文档、飞书知识库作为内容源。
- 以目录树展示目标源，支持选择单篇、目录节点或整个目标源。
- 默认每 30 分钟检测一次，也支持手动检测；检测与发布分离。
- 将新增、更新、删除变更汇总为待确认列表，允许拆分发布批次。
- 通过本地 Git 工作副本生成差异、提交并推送到 GitHub。
- 首次发布时创建系统维护的 `.github/easyblog.yml`。

## 3. 核心约束

- 内容源单向发布到 GitHub，GitHub 不反向写回。
- 每篇目标文章只能绑定一个来源；重复来源、slug 冲突和目标端外部修改阻止对应发布。
- 删除默认只标记为待删除，必须用户确认后才删除线上文件。
- 飞书内容转换为 Markdown；图片和附件同步到资源目录，不支持的富文本显示警告。
- 凭证仅存系统安全存储，SQLite 不保存 Secret 或 Token 明文；日志不得包含正文和凭证。
- 权限、网络、转换或状态不确定时停止受影响操作，不删除、不覆盖、不标记成功。

## 4. 首版验收

用户能够连接至少一个本地目录、一个飞书同步范围和一个 GitHub 博客目标，检测并预览变更，确认后完成内容与资源发布；失败可重试，历史可回滚。

# GitHub 发布

GitHub 使用本地 Git 工作副本。easyBlog 读取目标仓库、生成适配器所需的文章与资源文件、展示 diff，用户确认后创建一个批次提交并推送。用户可按文章、来源或目录拆分批次。

首版只支持一个明确的 GitHub Pages 博客模板适配器。统一内容模型由适配器生成 Front Matter、slug、文章目录和资源目录；目标结构不匹配时只读检查并提示。

首次发布前若缺少配置，预览中加入 `.github/easyblog.yml` 初始化变更并与首批内容一起提交。该文件由系统维护，只保存适配器和目录等非敏感配置，不创建 GitHub Actions。

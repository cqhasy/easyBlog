# 同步模型

## 来源与范围

内容源包括本地根目录、飞书文档和飞书知识库。每个源可配置多个同步范围；每个范围绑定一个 GitHub 发布目标，并支持包含/排除规则、递归子页面和暂停。目录树用于浏览、选择和展示状态。

选择整个源建立持续检测范围；新建、修改、移动和删除只进入待确认列表，不自动上线。停用或删除范围不自动删除线上内容。

## 状态与冲突

SQLite 保存来源 ID、范围、目标映射、内容哈希、检测结果和发布历史。文章路径只能绑定一个来源。相同来源重复纳入同一目标时合并；跨目标重叠、slug 冲突或目标文件存在外部修改时阻止发布并显示差异。

## 调度

默认每 30 分钟检测一次，可选 10 分钟、1 小时、6 小时、每天或关闭。应用启动后检测一次，退出时不运行；提供立即检测按钮。
